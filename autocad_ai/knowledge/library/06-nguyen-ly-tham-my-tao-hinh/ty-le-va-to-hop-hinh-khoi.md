# Nguyên Lý Tỷ Lệ & Tổ Hợp Hình Khối Kiến Trúc (Proportion & Massing)

Tài liệu cung cấp nền tảng lý thuyết hình học, hệ thống tỷ lệ kinh điển và các nguyên tắc tổ hợp hình khối không gian 3 chiều giúp đồ án đạt tính hài hòa thị giác, nhịp điệu và trật tự phân cấp.

---

## 1. Các Hệ Thống Tỷ Lệ Kinh Điển

### 1.1 Tỷ lệ vàng (Golden Ratio - $\phi \approx 1.618$)
- **Khái niệm:** Đoạn thẳng chia thành 2 phần sao cho: $\frac{A + B}{A} = \frac{A}{B} = 1.618$.
- **Ứng dụng:**
  - Tỷ lệ khung mặt tiền nhà: Chiều cao / Chiều rộng $\approx 1.618$ (hoặc $1 : 1.618$).
  - Tỷ lệ chia mảng đặc/rỗng trên mặt đứng (Solid-to-Void ratio).
  - Tỷ lệ phân chia chiều dài mặt bằng: Khu sinh hoạt chính chiếm $\approx 62\%$, khu phụ trợ chiếm $\approx 38\%$.

### 1.2 Dãy số Fibonacci ($1, 1, 2, 3, 5, 8, 13, 21, ...$)
- Tỷ lệ giữa hai số liền kề tiệm cận đến số vàng ($5:3 \approx 1.667$; $8:5 = 1.6$; $13:8 = 1.625$).
- **Ứng dụng:** Chia nhịp cửa sổ, lam chớp trang trí, phân chia mảng khối lùi/nhô trên mặt tiền theo tỷ lệ nhịp điệu $2 : 3 : 5$.

### 1.3 Hệ Modulor của Le Corbusier
- Dựa trên chiều cao người đứng giơ tay ($226\text{cm}$) và tỷ lệ vàng:
  - Rốn người ($113\text{cm}$).
  - Đỉnh đầu ($183\text{cm}$).
  - Tầm với tay ($226\text{cm}$).
- **Ứng dụng:** Định hình chiều cao bậu cửa sổ ($86\text{cm}$), chiều cao mặt bàn ($70-75\text{cm}$), chiều cao trần nhà tối thiểu ($226\text{cm}$).

## 2. Tỷ Lệ Đặc - Rỗng Mặt Đứng Công Trình (Solid-to-Void Ratio)

```
  MẶT ĐỨNG HIỆN ĐẠI (Glass / Void 40-50%)    MẶT ĐỨNG ĐÔNG DƯƠNG / TỐI GIẢN (Solid 70%)
  +-------------------------------------+    +-------------------------------------+
  | [ CỬA KÍNH LỚN ]   [ BAN CÔNG ]     |    |   [CỬA SỔ]              [CỬA SỔ]   |
  | [              ]   [          ]     |    |   +------+              +------+   |
  |                                     |    |   |      |              |      |   |
  | [ CỬA KÍNH TRỆT]   [ CỔNG MỞ ]      |    |   +------+              +------+   |
  +-------------------------------------+    +-------------------------------------+
```

| Phong cách kiến trúc | Tỷ lệ Mảng rỗng (Kính / Lỗ mở) | Tỷ lệ Mảng đặc (Tường xây / Bê tông) | Cảm xúc không gian |
|---|---|---|---|
| **Hiện đại (Modern Glass Facade)** | **$40\% – 55\%$** | $45\% – 60\%$ | Thooáng đạt, kết nối trong - ngoài, nhẹ nhàng |
| **Tối giản (Minimalism / Brutalism)** | **$20\% – 30\%$** | $70\% – 80\%$ | Kín đáo, tĩnh lặng, vững chãi, bí ẩn |
| **Đông Dương (Indochine) / Nhiệt đới** | **$30\% – 40\%$** | $60\% – 70\%$ | Cân bằng vi khí hậu, chắn nắng che mưa |
| **Tân cổ điển (Neoclassical)** | **$30\% – 35\%$** | $65\% – 70\%$ | Trang nghiêm, trật tự đối xứng chuẩn mực |

## 3. Các Nguyên Tắc Tổ Hợp Hình Khối 3D (Massing Principles)

1. **Phân cấp Chính - Phụ (Hierarchy):**
   - Công trình phải có một khối chủ đạo (Dominant mass) vượt trội về kích thước, chiều cao hoặc chất cảm vật liệu.
   - Các khối phụ (Secondary/Tertiary mass) làm nhiệm vụ nâng đỡ, bổ trợ cho khối chính, không cạnh tranh thị giác.
2. **Độ sâu mặt đứng (Depth & Layering):**
   - Tuyệt đối tránh mặt đứng phẳng lì một mặt phẳng đơn điệu.
   - Tạo các lớp lang thị giác qua việc giật khối thụt vào (Setback), nhô ra (Cantilever), ban công lùi sâu và hệ lam che nắng tạo bóng đổ phong phú dưới ánh sáng mặt trời.
3. **Quy tắc 3 Khối / 3 Vật liệu:**
   - Không phối quá 3 loại vật liệu hoàn thiện chính trên 1 diện mặt tiền để tránh hỗn loạn thị giác (Ví dụ: Bê tông trần + Gỗ teak + Kính đen).
